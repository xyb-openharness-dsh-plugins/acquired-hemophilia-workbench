# PATIENT-FLOW · 获得性血友病工作台

## 病程三段（按指南内容边界划分，不做分期判定）
1. **急症期**（出血发作 → 止血）：痛点=不知道该不该去急诊、用了什么药记不住。落点：今天页状态卡（出血中第 N 天）+ 出血与诱因 + 止血治疗按次。
2. **治疗期**（免疫抑制清除抑制物）：痛点=激素/免疫抑制剂减量、副作用与感染监测。落点：日常用药与调药 + INH/FⅧ:C 趋势 + 医嘱原话登记。
3. **随访期**（缓解监测复发）：痛点=滴度复测节律、哪些信号要警惕。落点：距上次出血天数、复测提醒（以医生安排为准，不自动判定）、就诊准备。

## 每段的患者旅程（假设，0 访谈）
- 进入：确诊通知/复查当天 → 打开工作台看「今天」页。
- 记录：出血一条、化验一条、治疗一笔（表单 ≤6 字段，三态保存）。
- 回顾：指标卡翻面看走势；一图秀按方法分组看曲线。
- 行动：复诊前导出预览 + 问题清单；紧急时看医生行动计划原话卡。
- 出口：所有页面有「和 AI 讨论」候选通道（只填不发）与回首页路径。

## 空态与缺失
- 新档案无记录：今天页给「记一次出血 →」CTA，不出空壳。
- 未知日期/未知诱因：显式「未知」，不猜。
- 无医生行动计划：行动卡空态「什么时候该联系医生，请直接问医生」。
