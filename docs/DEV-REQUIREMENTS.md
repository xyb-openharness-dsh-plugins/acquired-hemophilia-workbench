# DEV-REQUIREMENTS · acquired-hemophilia-workbench

## 一、患者视角红线
- 功能按患者关心维度组织：这次出血怎么记、化验单怎么看、激素/免疫抑制剂减量怎么跟上、下次就诊问什么；医生任务冒充患者需求属独立评审一票否决。
- 患者原话：0 访谈，全部为设计假设并标注「待访谈核实」，不冒充一手引语。

## 二、事实与来源红线
- 医学阈值（APTT 参考范围、抑制物阳性界值、随访频率）一律【待核】占位或引用指南原文并带来源行；不写自动判定。
- 指南只定内容边界：出血—止血、抑制物清除、随访节律；不转成自测或选治疗。
- 中国适应证/规范只认中国官方来源（卫健委 2025 版指南等）；国际来源标注「二次来源·未取得原件」。

## 三、裁剪声明（可执行验收：设置·临床数据库 tab 有此行）
- 临床试验线裁剪：AHA 年发病率约 1–1.5/百万（指南原文口径）、患者多在急症期，公开登记以病例登记研究（CARE/EACH2）为主；统一检索通道对罕见出血病召回不可靠。本台不建试验匹配线，设置 tab 与临床研究页如实写裁剪理由，不静默缺失。

## 四、可执行验收约定
- 「两套演示数据联动」= A/B 切换后页头档案名、看板、指标、区间带、导出抽查不串档（probe-acquired-hemophilia-m2 Q10 断言）。
- 「私密过滤」= 看板摘要/导出/AI 上下文三处各 1 条私密记录实测（Q35a/b/c 断言）。
- 「阈值待核」= 全站 grep「待核」≥1；grep 自动判定类话术（「你已进入」「属于 N 级」「复发」作界面判定）= 0。

## 五、可回退默认值（夜间无人值守 · 待晨审追认）
1. 服务主体：确诊/拟诊获得性血友病成人患者，家属协助代记；不覆盖儿童先天血友病。
2. 病程覆盖：确诊后全病程（急症止血 → 免疫抑制治疗 → 减量与复发监测）；妊娠/产后相关 AHA 只按事实记录，不设专门模块。
3. MinerU：不接入（六部件形态就位、如实标注「勾选与保存不联网」）。
4. 品牌占位名：小凝宝 CoagPal（与 TTP 小宁宝字形不同、英文不同；发布前由用户定夺）。
5. AI 原生对话：演示态；装机形态按会话授权走宿主原生会话。
