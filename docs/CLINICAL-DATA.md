# CLINICAL-DATA · 临床数据口径

## 数据边界（指南只定内容边界）
- 本台陈列：aPTT、FⅧ:C、抑制物滴度（Bethesda/Nijmegen）、Hb/WBC/PLT、体重；出血事件；止血/免疫抑制/调药按次；医嘱原话。
- 本台不做：诊断、抑制物阳性判定（滴度数值只陈列，「≥0.6 BU/ml 为阳性」仅出现在疾病概要来源行）、复发判定、疗效分级、血栓/出血风险评估。
