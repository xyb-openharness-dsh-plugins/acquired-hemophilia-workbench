## 差异化矩阵（≥3 条，场景→功能→验收）
1. 出血发作时间线：场景=突发大片瘀斑/肌肉血肿，想给医生看「距上次出血多久、当时怎么处理」→功能=出血折叠记录+事件泳道（色带=出血期间，○=出血停止，◆=治疗）→验收=probe Q10 A/B 切换不串档；timeline 路由非空。
2. 凝血指标可比组：场景=aPTT 在两家医院不同试剂方法报告→功能=按「方法+机构」分组陈列，跨方法不合并/不连线/不做差→验收=demo B 硅土法 vs 白陶土法双机构数据；MT06 类断言（labs 列表分组渲染）+ 一图秀分组断线。
3. 抑制物滴度复测线：场景=想知道「滴度从 45 降到 0.4 又升到 2.8 怎么回事」→功能=INH 单列趋势（Bethesda/Nijmegen 方法标注，只陈列）→验收=records/metrics 卡片含 INH，翻面走势同源 demo 数据。
4. 紧急行动卡：场景=出血加重时不知该不该去急诊→功能=只呈现医生已确认的行动计划原话，无确认时空态引导问医生→验收=Q19 断言（AI 上下文无判定词）+ 界面无「你已复发」类文案（check-wording）。
5. 试验线裁剪：场景=听到某项登记研究想核对→功能=如实裁剪说明+登记号交给医生核对→验收=CLIN0 断言（明示理由+下一步+无假检索/假分数）。
